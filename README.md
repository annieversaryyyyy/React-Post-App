#  Blog App - React + Firebase

This is a simple blog application built with **React** and **Firebase Realtime Database**, where users can create, view, edit, and delete posts.  
The project demonstrates clean architecture, controlled form inputs, routing, error handling.

---

##  Features

- Create new posts with a title and description  
- Edit existing posts  
- Delete posts  
- Automatic ID generation using `crypto.randomUUID()`  
- Timestamp added to each post on creation  
- Toast notifications for creating, editing, and deleting posts
- Pagination for navigating pages of posts
- Error handling for failed API requests 
- **Tech Stack:** React, React Router, Firebase Realtime Database, Axios
